# Báo cáo triển khai Use Case: UC-01 Secure Handshake

## 1. Mô tả chi tiết
Use case **Secure Handshake (Trao đổi khóa bảo mật)** được tự động kích hoạt ngay khi Client thiết lập kết nối TCP thành công đến Server. Quá trình này thiết lập một kênh truyền an toàn, mã hóa bằng thuật toán AES. 
Quá trình triển khai thực tế tuân thủ nghiêm ngặt thiết kế ban đầu:
- Server quản lý vòng đời RSA Key (`RsaManager`).
- Client sinh ngẫu nhiên AES Key và IV, sử dụng RSA Public Key của Server để mã hóa và gửi lại.
- Sau khi trao đổi thành công, thuộc tính `Cipher` của `SessionHandler` được gán để tự động mã hóa mọi dữ liệu `Payload` tiếp theo.

## 2. Thiết kế lớp chi tiết (Class Design)
Dưới đây là sơ đồ lớp chi tiết thể hiện các thành phần tham gia vào luồng Handshake:

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
        +RoutingKey: string
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ClientHandshakePubKeyHandler {
        +RoutingKey: string = "auth.handshake.pubkey"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ClientHandshakeDoneHandler {
        +RoutingKey: string = "auth.handshake.done"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerHandshakeReqHandler {
        +RoutingKey: string = "auth.handshake.req"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerHandshakeResHandler {
        +RoutingKey: string = "auth.handshake.res"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class RsaManager {
        +GetPublicKey() string
        +Decrypt(data: byte[]) byte[]
    }

    class AesCipher {
        +Encrypt(data: byte[]) byte[]
        +Decrypt(data: byte[]) byte[]
    }

    class ServerSecurityState {
        <<static>>
        +RsaManager: RsaManager
    }

    IMessageHandler <|-- ClientHandshakePubKeyHandler
    IMessageHandler <|-- ClientHandshakeDoneHandler
    IMessageHandler <|-- ServerHandshakeReqHandler
    IMessageHandler <|-- ServerHandshakeResHandler
    
    ServerHandshakeReqHandler ..> ServerSecurityState : Lấy Public Key
    ServerHandshakeResHandler ..> ServerSecurityState : Giải mã AES Key
    ServerHandshakeResHandler ..> AesCipher : Khởi tạo & Gán vào Session
    ClientHandshakePubKeyHandler ..> AesCipher : Khởi tạo & Gán vào Session
```

## 3. Biểu đồ tuần tự (Sequence Diagram)
Biểu đồ tuần tự chi tiết mô tả quá trình trao đổi khóa và chuyển trạng thái của Session sang đã mã hóa (IsEncrypted = true).

```mermaid
sequenceDiagram
    participant Client as LanChat Client
    participant Server as LanChat Server (SessionHandler)
    participant ReqHandler as ServerHandshakeReqHandler
    participant ResHandler as ServerHandshakeResHandler
    participant ClientPubKeyHandler as ClientHandshakePubKeyHandler
    participant ClientDoneHandler as ClientHandshakeDoneHandler
    
    Client->>Server: Connect TCP (Port 8080)
    activate Server
    Server-->>Client: Connection Accepted
    
    Note over Client: Bắt đầu quá trình Handshake
    Client->>Server: Packet [RoutingKey="auth.handshake.req"]
    Server->>ReqHandler: HandleAsync(Payload)
    activate ReqHandler
    ReqHandler->>ReqHandler: Lấy RSA Public Key từ ServerSecurityState
    ReqHandler-->>Client: Packet [RoutingKey="auth.handshake.pubkey", Payload=HandshakePubKeyPayload]
    deactivate ReqHandler
    
    Client->>ClientPubKeyHandler: HandleAsync(Payload)
    activate ClientPubKeyHandler
    ClientPubKeyHandler->>ClientPubKeyHandler: Sinh ngẫu nhiên AES Key & IV
    ClientPubKeyHandler->>ClientPubKeyHandler: Gán session.Cipher = AesCipher(Key, IV)
    ClientPubKeyHandler->>ClientPubKeyHandler: Mã hóa AES Key & IV bằng RSA Public Key
    ClientPubKeyHandler->>Server: Packet [RoutingKey="auth.handshake.res", Payload=HandshakeResponsePayload]
    deactivate ClientPubKeyHandler
    
    Server->>ResHandler: HandleAsync(Payload)
    activate ResHandler
    ResHandler->>ResHandler: Giải mã AES Key & IV bằng RSA Private Key
    ResHandler->>ResHandler: Gán session.Cipher = AesCipher(Key, IV)
    Note over ResHandler: Từ thời điểm này trở đi, Payload được mã hóa AES
    ResHandler-->>Client: Packet [RoutingKey="auth.handshake.done"] (Mã hóa AES)
    deactivate ResHandler
    
    Client->>ClientDoneHandler: HandleAsync(Payload)
    activate ClientDoneHandler
    ClientDoneHandler->>ClientDoneHandler: Xác nhận giải mã thành công
    ClientDoneHandler->>ClientDoneHandler: Đặt thuộc tính session.IsEncrypted = true
    deactivate ClientDoneHandler
    
    Note over Client, Server: Kênh giao tiếp TCP đã được bảo vệ hoàn toàn bằng AES
```
