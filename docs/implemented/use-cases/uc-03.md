# Báo cáo triển khai Use Case: UC-03 User Login

## 1. Mô tả chi tiết
Use case **User Login (Đăng nhập)** cho phép người dùng xác thực và truy cập vào hệ thống.
Quá trình này kiểm tra thông tin trong CSDL qua `AppDbContext` và đối chiếu mật khẩu sử dụng `IPasswordHasher`.
Sau khi đăng nhập thành công, Server gán Username cho `SessionHandler` hiện tại, đăng ký session này với `SessionManager` để quản lý tập trung, trả về kết quả thành công và tiến hành broadcast `user.joined` cho các người dùng khác biết người này vừa online.

## 2. Thiết kế lớp chi tiết (Class Design)
Dưới đây là sơ đồ lớp chi tiết của quá trình đăng nhập:

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
        +RoutingKey: string
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerLoginHandler {
        +RoutingKey: string = "auth.login.req"
        -_serviceProvider: IServiceProvider
        -_passwordHasher: IPasswordHasher
        -_sessionManager: SessionManager
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class IPasswordHasher {
        <<interface>>
        +HashPassword(password: string) string
        +VerifyPassword(password: string, hash: string) bool
    }

    class SessionManager {
        +AddOrUpdateSession(username: string, session: SessionHandler)
        +Snapshot() Dictionary<string, SessionHandler>
    }

    class AppDbContext {
        +Users: DbSet<User>
    }

    class User {
        +Id: Guid
        +Username: string
        +PasswordHash: string
    }

    IMessageHandler <|-- ServerLoginHandler
    ServerLoginHandler --> IPasswordHasher : Xác minh mật khẩu
    ServerLoginHandler --> SessionManager : Quản lý phiên
    ServerLoginHandler ..> AppDbContext : Truy vấn CSDL
    AppDbContext --> User : Entity
```

## 3. Biểu đồ tuần tự (Sequence Diagram)
Biểu đồ tuần tự mô tả chi tiết các bước xác thực và phát sóng trạng thái online.

```mermaid
sequenceDiagram
    participant Client as LanChat Client
    participant Server as LanChat Server (SessionHandler)
    participant Handler as ServerLoginHandler
    participant DB as AppDbContext
    participant Hasher as IPasswordHasher
    participant SManager as SessionManager
    participant OtherClients as Các Client khác
    
    Client->>Server: Packet [RoutingKey="auth.login.req", Payload=LoginRequestPayload]
    Server->>Handler: HandleAsync(Payload)
    activate Handler
    
    Handler->>DB: FirstOrDefaultAsync(u => u.Username == request.Username)
    activate DB
    DB-->>Handler: user (Entity hoặc null)
    deactivate DB
    
    alt user == null 
        Handler-->>Client: Packet [auth.login.res, Success=false, Message="Sai tên..."]
    else user != null
        Handler->>Hasher: VerifyPassword(request.Password, user.PasswordHash)
        activate Hasher
        Hasher-->>Handler: isValid (bool)
        deactivate Hasher
        
        alt isValid == false
            Handler-->>Client: Packet [auth.login.res, Success=false, Message="Sai tên..."]
        else isValid == true
            Handler->>Handler: session.Username = user.Username
            Handler->>SManager: AddOrUpdateSession(user.Username, session)
            
            Handler-->>Client: Packet [auth.login.res, Success=true, Message="Đăng nhập thành công"]
            
            Handler->>SManager: Snapshot() (Lấy danh sách session đang online)
            activate SManager
            SManager-->>Handler: sessions
            deactivate SManager
            
            loop Mỗi otherSession trong sessions
                opt otherSession.Key != user.Username
                    Handler->>OtherClients: Packet [RoutingKey="user.joined", Payload=UserPresencePayload]
                end
            end
        end
    end
    
    deactivate Handler
```
