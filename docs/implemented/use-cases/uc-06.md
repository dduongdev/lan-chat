# Báo cáo triển khai Use Case: UC-06 File Transfer

## 1. Mô tả chi tiết
Use case **File Transfer (Truyền File & Lưu Lịch Sử)** được triển khai theo kiến trúc Store & Forward kết hợp 2 luồng riêng biệt:
1. **Control Plane (Port 8080 - TCP)**: Quản lý Metadata của file. Client gửi yêu cầu `file.upload.req` hoặc `file.download.req`. Server tạo bản ghi trong bảng `FileTransfer`, xác thực quyền truy cập, sau đó sinh ra một `TransferToken` thông qua `FileStreamManager`.
2. **Data Plane (Port 8081 - TCP)**: Chuyên trách truyền dòng dữ liệu (Stream) thực tế thông qua `FileStreamHandler`. Client mang `TransferToken` kết nối tới cổng này để upload hoặc download bytes nhị phân, giảm tải cho luồng Control.

## 2. Thiết kế lớp chi tiết (Class Design)
Dưới đây là sơ đồ lớp các thành phần tham gia (tập trung vào Control Plane):

```mermaid
classDiagram
    class ServerFileUploadHandler {
        +RoutingKey: string = "file.upload.req"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerFileDownloadHandler {
        +RoutingKey: string = "file.download.req"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class FileStreamManager {
        +RegisterToken(token: Guid, context: TransferContext)
        +ValidateAndConsumeToken(token: Guid) TransferContext
    }

    class AppDbContext {
        +FileTransfers: DbSet<FileTransfer>
        +Users: DbSet<User>
    }

    class FileTransfer {
        +Id: Guid
        +UploaderId: Guid
        +TargetType: string
        +TargetId: string
        +FileName: string
        +Status: string
    }

    ServerFileUploadHandler ..> AppDbContext : Ghi Metadata (Uploading)
    ServerFileUploadHandler --> FileStreamManager : Sinh Token Upload
    
    ServerFileDownloadHandler ..> AppDbContext : Kiểm tra quyền & Trạng thái (Available)
    ServerFileDownloadHandler --> FileStreamManager : Sinh Token Download
    
    AppDbContext --> FileTransfer : Quản lý Entity
```

## 3. Biểu đồ tuần tự (Sequence Diagram)
Biểu đồ mô tả quá trình cấp phát Token upload và download.

```mermaid
sequenceDiagram
    participant Uploader as Client (Người gửi)
    participant ServerControl as Server (Port 8080)
    participant DB as AppDbContext
    participant FSManager as FileStreamManager
    participant Downloader as Client (Người nhận)
    
    Note over Uploader, FSManager: --- QUÁ TRÌNH UPLOAD ---
    Uploader->>ServerControl: Packet [RoutingKey="file.upload.req", Payload=FileUploadRequestPayload]
    activate ServerControl
    ServerControl->>DB: Khởi tạo FileTransfer (Status="Uploading")
    ServerControl->>DB: SaveChangesAsync()
    ServerControl->>FSManager: RegisterToken(Upload_Action)
    FSManager-->>ServerControl: uploadToken
    ServerControl-->>Uploader: Packet [RoutingKey="file.transfer.res", Action="UPLOAD", Token=uploadToken]
    deactivate ServerControl
    
    Note over Uploader: Client mang uploadToken kết nối Port 8081 để stream dữ liệu
    
    Note over Downloader, FSManager: --- QUÁ TRÌNH DOWNLOAD ---
    Downloader->>ServerControl: Packet [RoutingKey="file.download.req", FileId]
    activate ServerControl
    ServerControl->>DB: Kiểm tra quyền & Status=="Available"
    ServerControl->>FSManager: RegisterToken(Download_Action)
    FSManager-->>ServerControl: downloadToken
    ServerControl-->>Downloader: Packet [RoutingKey="file.transfer.res", Action="DOWNLOAD", Token=downloadToken]
    deactivate ServerControl
    
    Note over Downloader: Client mang downloadToken kết nối Port 8081 để nhận dữ liệu
```
