# Báo cáo triển khai Use Case: UC-07 User Logout / Disconnect

## 1. Mô tả chi tiết
Use case **User Logout / Disconnect (Đăng xuất / Ngắt kết nối)** quản lý việc người dùng chủ động rời mạng hoặc bị đứt kết nối. 
Luồng sự kiện đi qua `ServerLogoutHandler` (chủ động) hoặc ngắt kết nối vật lý. Trong cả hai trường hợp, `SessionManager.HandleDisconnectAsync()` đều được gọi để dọn dẹp bộ nhớ, gửi broadcast `user.left` tới những người còn lại để họ cập nhật UI kịp thời.

## 2. Thiết kế lớp chi tiết (Class Design)

```mermaid
classDiagram
    class ServerLogoutHandler {
        +RoutingKey: string = "auth.logout.req"
        -_sessionManager: SessionManager
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class SessionManager {
        -sessions: ConcurrentDictionary<string, SessionHandler>
        +HandleDisconnectAsync(session: SessionHandler) Task
        +RemoveSession(username: string)
    }

    class ServerHeartbeatHandler {
        +RoutingKey: string = "sys.ping"
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    ServerLogoutHandler --> SessionManager : Ủy quyền xử lý ngắt kết nối
```

## 3. Biểu đồ tuần tự (Sequence Diagram)

```mermaid
sequenceDiagram
    participant Client as LanChat Client
    participant Server as LanChat Server
    participant Handler as ServerLogoutHandler
    participant SManager as SessionManager
    participant OtherClients as Các Client khác
    
    Client->>Server: Packet [RoutingKey="auth.logout.req"]
    Server->>Handler: HandleAsync(Payload)
    activate Handler
    
    Handler->>SManager: HandleDisconnectAsync(session)
    activate SManager
    
    SManager->>SManager: Xóa session khỏi ConcurrentDictionary
    
    SManager->>SManager: Snapshot() (Lấy danh sách các session còn lại)
    
    loop Mỗi session còn lại
        SManager->>OtherClients: Packet [RoutingKey="user.left", Payload=UserPresencePayload]
    end
    
    SManager->>Server: session.TcpClient.Close()
    
    deactivate SManager
    deactivate Handler
    
    Note over Client: Trở về màn hình Login
```
