# Báo cáo triển khai Use Case: UC-08 Group Management

## 1. Mô tả chi tiết
Use case **Group Management (Tạo nhóm chat và quản lý)** cho phép người dùng tạo nhóm mới, thêm thành viên vào nhóm, rời nhóm, và liệt kê các nhóm mình đang tham gia.
Tất cả dữ liệu về nhóm (`ChatGroup`) và thành viên (`GroupMember`) được lưu trong Database, đảm bảo dữ liệu nhóm có tính vĩnh viễn (Persistent). Khi có các thay đổi về thành viên, Server sẽ Broadcast các gói tin (`group.invite`, `group.member.added`, `group.member.left`) đến các thành viên Online liên quan.

## 2. Thiết kế lớp chi tiết (Class Design)

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
        +RoutingKey: string
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerGroupCreateHandler {
        +RoutingKey: string = "group.create.req"
        +HandleAsync(...) Task
    }

    class ServerGroupAddHandler {
        +RoutingKey: string = "group.add.req"
        +HandleAsync(...) Task
    }

    class ServerGroupListHandler {
        +RoutingKey: string = "group.list.req"
        +HandleAsync(...) Task
    }

    class ServerGroupLeaveHandler {
        +RoutingKey: string = "group.leave.req"
        +HandleAsync(...) Task
    }

    class AppDbContext {
        +ChatGroups: DbSet~ChatGroup~
        +GroupMembers: DbSet~GroupMember~
    }

    class SessionManager {
        +TryGet(...) bool
    }

    IMessageHandler <|-- ServerGroupCreateHandler
    IMessageHandler <|-- ServerGroupAddHandler
    IMessageHandler <|-- ServerGroupListHandler
    IMessageHandler <|-- ServerGroupLeaveHandler
    
    ServerGroupCreateHandler ..> AppDbContext : Tạo Group & Members
    ServerGroupAddHandler ..> AppDbContext : Cập nhật Members
    ServerGroupListHandler ..> AppDbContext : Truy vấn
    ServerGroupLeaveHandler ..> AppDbContext : Xóa Member/Group
    
    ServerGroupCreateHandler --> SessionManager : Broadcast Invite
    ServerGroupAddHandler --> SessionManager : Broadcast Updates
    ServerGroupLeaveHandler --> SessionManager : Broadcast Left
```

## 3. Biểu đồ tuần tự (Sequence Diagram - Group Create)
Dưới đây là biểu đồ tạo nhóm điển hình. Các luồng (Add/Leave/List) cũng theo mô hình tương tự: Truy vấn DB -> Cập nhật -> Broadcast cho Online Users.

```mermaid
sequenceDiagram
    participant Creator as Client (Người tạo)
    participant Server
    participant Handler as ServerGroupCreateHandler
    participant DB as AppDbContext
    participant SManager as SessionManager
    participant Members as Clients (Thành viên)
    
    Creator->>Server: Packet [RoutingKey="group.create.req", Payload=GroupCreateRequestPayload]
    Server->>Handler: HandleAsync(Payload)
    activate Handler
    
    Handler->>Handler: Validate Request
    Handler->>DB: Khởi tạo ChatGroup Entity
    Handler->>DB: Khởi tạo GroupMember (Creator + InitialMembers)
    Handler->>DB: SaveChangesAsync()
    activate DB
    DB-->>Handler: Success (Sinh GroupId)
    deactivate DB
    
    Handler-->>Creator: Packet [RoutingKey="group.create.res", Success=true, GroupId]
    
    loop Mỗi thành viên được mời (khác Creator)
        Handler->>SManager: TryGet(Member.Username)
        alt isOnline == true
            Handler->>Members: Packet [RoutingKey="group.invite", Payload=GroupInfoDto]
        end
    end
    
    deactivate Handler
```
