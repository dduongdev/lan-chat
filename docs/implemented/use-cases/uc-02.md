# Báo cáo triển khai Use Case: UC-02 User Registration

## 1. Mô tả chi tiết
Use case **User Registration (Đăng ký tài khoản)** cho phép người dùng mới đăng ký một tài khoản trên hệ thống LanChat.
Dữ liệu người dùng được lưu trữ lâu dài bằng Entity Framework Core (chứa trong `AppDbContext`). Để đảm bảo an toàn, hệ thống không lưu mật khẩu dạng plaintext mà tiến hành hash mật khẩu thông qua interface `IPasswordHasher` (sử dụng thuật toán an toàn) trước khi ghi vào CSDL.

## 2. Thiết kế lớp chi tiết (Class Design)
Dưới đây là sơ đồ lớp chi tiết của quá trình đăng ký:

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
        +RoutingKey: string
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerRegisterHandler {
        +RoutingKey: string = "auth.register.req"
        -_serviceProvider: IServiceProvider
        -_passwordHasher: IPasswordHasher
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class IPasswordHasher {
        <<interface>>
        +HashPassword(password: string) string
        +VerifyPassword(password: string, hash: string) bool
    }

    class AppDbContext {
        +Users: DbSet<User>
        +SaveChangesAsync() Task<int>
    }

    class User {
        +Id: Guid
        +Username: string
        +PasswordHash: string
    }

    IMessageHandler <|-- ServerRegisterHandler
    ServerRegisterHandler --> IPasswordHasher : Sử dụng để Hash
    ServerRegisterHandler ..> AppDbContext : Truy vấn & Lưu dữ liệu
    AppDbContext --> User : Quản lý Entity
```

## 3. Biểu đồ tuần tự (Sequence Diagram)
Biểu đồ tuần tự dưới đây thể hiện luồng xử lý từ khi Client gửi yêu cầu đăng ký đến khi Server phản hồi.

```mermaid
sequenceDiagram
    participant Client as LanChat Client
    participant Server as LanChat Server (SessionHandler)
    participant Handler as ServerRegisterHandler
    participant Hasher as IPasswordHasher
    participant DB as AppDbContext
    
    Client->>Server: Packet [RoutingKey="auth.register.req", Payload=RegisterRequestPayload]
    Server->>Handler: HandleAsync(Payload)
    activate Handler
    
    Handler->>Handler: Validate Payload (Null/Empty)
    
    Handler->>DB: AnyAsync(u => u.Username == request.Username)
    activate DB
    DB-->>Handler: bool (usernameExists)
    deactivate DB
    
    alt usernameExists == true
        Handler-->>Client: Packet [RoutingKey="auth.register.res", Success=false, Message="Tên đăng nhập đã tồn tại."]
    else usernameExists == false
        Handler->>Hasher: HashPassword(request.Password)
        activate Hasher
        Hasher-->>Handler: passwordHash
        deactivate Hasher
        
        Handler->>Handler: Khởi tạo User Entity mới
        Handler->>DB: Users.Add(newUser)
        Handler->>DB: SaveChangesAsync()
        activate DB
        DB-->>Handler: Cập nhật thành công
        deactivate DB
        
        Handler-->>Client: Packet [RoutingKey="auth.register.res", Success=true, Message="Đăng ký thành công."]
    end
    
    deactivate Handler
```
