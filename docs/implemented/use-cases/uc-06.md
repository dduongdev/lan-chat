# Báo cáo triển khai Use Case: UC-06 File Transfer

## 1. Mô tả chi tiết
Use case **File Transfer (Truyền File & Lưu Lịch Sử)** được triển khai theo kiến trúc Store & Forward kết hợp 2 luồng riêng biệt để đảm bảo hiệu suất và bảo mật:
1. **Control Plane (Port 8080 - TCP)**: Quản lý Metadata của file và kiểm soát truy cập. 
   - Khi có yêu cầu Upload (`file.upload.req`), Server khởi tạo một bản ghi `FileTransfer` (Trạng thái: "Uploading") và trả về một `TransferToken` thông qua `FileStreamManager`.
   - Khi có yêu cầu Download (`file.download.req`), Server kiểm tra phân quyền và trạng thái file ("Available"), nếu hợp lệ cũng sẽ trả về một `TransferToken`.
2. **Data Plane (Port 8081 - TCP)**: Chuyên trách luồng nhị phân thông qua `FileStreamManager`. 
   - Client kết nối đến port này, gửi 16 bytes chứa `TransferToken` để xác thực.
   - Nếu là Upload, Server đọc luồng và ghi vào file vật lý, tính toán lại mã SHA-256 để đối chiếu. Nếu toàn vẹn, cập nhật trạng thái "Available", tự động sinh bản ghi `Message` (loại "File") và kích hoạt Broadcast thông báo qua gói tin `chat.receive` (hoạt động giống như gửi tin nhắn thông thường). Nếu sai hash, file bị xóa và trạng thái chuyển thành "Corrupted".
   - Nếu là Download, Server đọc file từ đĩa và gửi qua stream.

## 2. Thiết kế lớp chi tiết (Class Design)

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
    }

    class ServerFileUploadHandler {
        +RoutingKey: string = "file.upload.req"
        +HandleAsync(...) Task
    }

    class ServerFileDownloadHandler {
        +RoutingKey: string = "file.download.req"
        +HandleAsync(...) Task
    }

    class FileStreamManager {
        -DataPort: int = 8081
        -_tokenStore: ConcurrentDictionary<Guid, TransferContext>
        +RegisterToken(token: Guid, context: TransferContext)
        +Start()
        -AcceptLoopAsync() Task
        -HandleClientAsync(client: TcpClient) Task
        -HandleUploadAsync(...) Task
        -HandleDownloadAsync(...) Task
        -NotifyFileAvailableAsync(...) Task
    }

    class AppDbContext {
        +FileTransfers: DbSet<FileTransfer>
        +Messages: DbSet<Message>
    }

    class FileTransfer {
        +Id: Guid
        +UploaderId: Guid
        +StoragePath: string
        +FileHash: string
        +Status: string
    }

    IMessageHandler <|-- ServerFileUploadHandler
    IMessageHandler <|-- ServerFileDownloadHandler
    
    ServerFileUploadHandler ..> AppDbContext : Ghi Metadata
    ServerFileUploadHandler --> FileStreamManager : Sinh Upload Token
    
    ServerFileDownloadHandler ..> AppDbContext : Kiểm tra Quyền truy cập
    ServerFileDownloadHandler --> FileStreamManager : Sinh Download Token
    
    FileStreamManager ..> AppDbContext : Cập nhật Trạng thái & Tạo tin nhắn
```

## 3. Biểu đồ tuần tự (Sequence Diagram)
Dưới đây là sơ đồ chi tiết được chia thành 2 phần: Quá trình Upload và Quá trình Download.

### 3.1. Quá trình Upload
Biểu đồ minh họa quá trình Upload và phát thông báo khi file sẵn sàng.

```mermaid
sequenceDiagram
    participant Client as Client (Sender/Uploader)
    participant Receiver as Client (Receiver)
    participant Member as Client (Group Member)
    participant MainServer as Server (Control Plane 8080)
    participant UploadHandler as ServerFileUploadHandler
    participant DB as AppDbContext
    participant FSManager as FileStreamManager (Data Plane 8081)
    participant SManager as SessionManager
    
    %% ================= QUÁ TRÌNH UPLOAD =================
    Note over Client, SManager: 1. GIAI ĐOẠN XIN CẤP PHÉP UPLOAD (CONTROL PLANE)
    Client->>MainServer: Packet [RoutingKey="file.upload.req", Payload=FileUploadRequestPayload]
    MainServer->>UploadHandler: HandleAsync(Payload)
    activate UploadHandler
    
    UploadHandler->>DB: Truy vấn Uploader qua Username
    DB-->>UploadHandler: User Entity
    
    UploadHandler->>UploadHandler: Sinh FileId (Guid) & storagePath ("{FileId}.dat")
    UploadHandler->>DB: Khởi tạo Entity FileTransfer (Status="Uploading")
    UploadHandler->>DB: SaveChangesAsync()
    
    UploadHandler->>UploadHandler: Sinh TransferToken (Guid)
    UploadHandler->>FSManager: RegisterToken(Token, TransferContext{Action="UPLOAD", ...})
    
    UploadHandler-->>Client: Packet [RoutingKey="file.transfer.res", Action="UPLOAD", Token]
    deactivate UploadHandler
    
    Note over Client, SManager: 2. GIAI ĐOẠN STREAM DỮ LIỆU UPLOAD (DATA PLANE)
    Client->>FSManager: Kết nối TCP (Port 8081)
    activate FSManager
    Client->>FSManager: Gửi 16 bytes TransferToken
    FSManager->>FSManager: ValidateToken(Token) & Kiểm tra ExpiresAt
    
    FSManager->>FSManager: HandleUploadAsync()
    Client->>FSManager: Truyền Stream nhị phân của file
    FSManager->>FSManager: Ghi vào FileStream (Uploads/{FileId}.dat)
    
    FSManager->>FSManager: Tính toán mã SHA-256 của file vừa lưu
    FSManager->>DB: Truy vấn FileTransfer (bằng FileId)
    DB-->>FSManager: FileTransfer Entity
    
    alt HashComputed == ExpectedHash
        FSManager->>DB: Cập nhật Status="Available"
        FSManager->>DB: SaveChangesAsync()
        
        FSManager->>FSManager: NotifyFileAvailableAsync()
        FSManager->>DB: Khởi tạo Entity Message (MessageType="File", Content="📎 {FileName}")
        FSManager->>DB: SaveChangesAsync()
        
        alt TargetType == "PRIVATE"
            FSManager->>SManager: TryGet(ReceiverUsername)
            FSManager->>Receiver: Packet [RoutingKey="chat.receive", MessageType="File"]
            FSManager->>SManager: TryGet(UploaderUsername)
            FSManager->>Client: Packet [RoutingKey="chat.receive"] (Xác nhận)
        else TargetType == "GROUP"
            FSManager->>DB: Truy vấn thành viên nhóm
            loop Mỗi thành viên
                FSManager->>SManager: TryGet(MemberUsername)
                FSManager->>Member: Packet [RoutingKey="chat.receive"]
            end
        end
    else HashComputed != ExpectedHash
        FSManager->>FSManager: Xóa file vật lý khỏi đĩa
        FSManager->>DB: Cập nhật Status="Corrupted"
        FSManager->>DB: SaveChangesAsync()
    end
    deactivate FSManager
```

### 3.2. Quá trình Download
Biểu đồ minh họa quá trình yêu cầu và tải file về máy khách.

```mermaid
sequenceDiagram
    participant Client as Client (Receiver/Downloader)
    participant MainServer as Server (Control Plane 8080)
    participant DownloadHandler as ServerFileDownloadHandler
    participant DB as AppDbContext
    participant FSManager as FileStreamManager (Data Plane 8081)
    participant SManager as SessionManager
    
    %% ================= QUÁ TRÌNH DOWNLOAD =================
    Note over Client, SManager: 3. GIAI ĐOẠN XIN CẤP PHÉP DOWNLOAD (CONTROL PLANE)
    Client->>MainServer: Packet [RoutingKey="file.download.req", Payload=FileDownloadRequestPayload]
    MainServer->>DownloadHandler: HandleAsync(Payload)
    activate DownloadHandler
    
    DownloadHandler->>DB: Truy vấn FileTransfer (Status == "Available")
    DB-->>DownloadHandler: FileTransfer Entity
    
    DownloadHandler->>DB: Kiểm tra ủy quyền (Is Uploader / Receiver / Group Member)
    DB-->>DownloadHandler: isAuthorized (bool)
    
    alt isAuthorized == true
        DownloadHandler->>DownloadHandler: Sinh TransferToken (Guid)
        DownloadHandler->>FSManager: RegisterToken(Token, TransferContext{Action="DOWNLOAD", ...})
        DownloadHandler-->>Client: Packet [RoutingKey="file.transfer.res", Success=true, Action="DOWNLOAD", Token]
    else isAuthorized == false
        DownloadHandler-->>Client: Packet [RoutingKey="file.transfer.res", Success=false]
    end
    deactivate DownloadHandler
    
    Note over Client, SManager: 4. GIAI ĐOẠN STREAM DỮ LIỆU DOWNLOAD (DATA PLANE)
    Client->>FSManager: Kết nối TCP (Port 8081)
    activate FSManager
    Client->>FSManager: Gửi 16 bytes TransferToken
    FSManager->>FSManager: ValidateToken(Token) & Kiểm tra ExpiresAt
    
    FSManager->>FSManager: HandleDownloadAsync()
    FSManager->>DB: Đảm bảo FileTransfer.Status == "Available"
    FSManager->>FSManager: Đọc FileStream từ đĩa (Uploads/{FileId}.dat)
    FSManager->>Client: Trả về Stream nhị phân của file
    deactivate FSManager
```
