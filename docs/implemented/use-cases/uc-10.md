# Báo cáo triển khai Use Case: UC-10 Chat History

## 1. Mô tả chi tiết
Use case **Chat History (Lấy lịch sử tin nhắn)** là một tính năng mở rộng nhằm cung cấp khả năng xem lại các tin nhắn cũ trong một cuộc trò chuyện (Cá nhân, Nhóm, hoặc Toàn mạng).
Khi nhận được yêu cầu, Server sẽ truy vấn Entity Framework (`AppDbContext`) để lấy danh sách tin nhắn thỏa mãn điều kiện `TargetType` và `TargetId`. Quá trình này có hỗ trợ phân trang (Pagination) thông qua tham số `BeforeTimestamp` và `Limit`.

## 2. Thiết kế lớp chi tiết (Class Design)

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
        +RoutingKey: string
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerChatHistoryHandler {
        +RoutingKey: string = "chat.history.req"
        -_serviceProvider: IServiceProvider
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class AppDbContext {
        +Users: DbSet<User>
        +Messages: DbSet<Message>
    }

    class Message {
        +Id: Guid
        +SenderId: Guid
        +ReceiverId: Guid?
        +GroupId: Guid?
        +Content: string
        +SentAt: DateTime
        +MessageType: string
        +FileId: Guid?
    }

    class ChatMessageDto {
        +ServerMessageId: Guid
        +Sender: string
        +Content: string
        +SentAt: DateTime
        +TargetType: string
        +TargetId: string
    }

    IMessageHandler <|-- ServerChatHistoryHandler
    ServerChatHistoryHandler ..> AppDbContext : Truy vấn tin nhắn
    AppDbContext --> Message : Quản lý Entity
    ServerChatHistoryHandler ..> ChatMessageDto : Map sang DTO
```

## 3. Biểu đồ tuần tự (Sequence Diagram)

```mermaid
sequenceDiagram
    participant Client as LanChat Client
    participant Server
    participant Handler as ServerChatHistoryHandler
    participant DB as AppDbContext
    
    Client->>Server: Packet [RoutingKey="chat.history.req", Payload=ChatHistoryRequestPayload]
    Server->>Handler: HandleAsync(Payload)
    activate Handler
    
    Handler->>DB: Truy vấn User hiện tại
    activate DB
    DB-->>Handler: User Entity
    
    Note over Handler, DB: Xây dựng Query IQueryable<Message>
    
    alt TargetType == "PRIVATE"
        Handler->>DB: Where(Sender == A & Receiver == B || Sender == B & Receiver == A)
    else TargetType == "GROUP"
        Handler->>DB: Where(GroupId == group.Id)
    else TargetType == "ALL"
        Handler->>DB: Where(ReceiverId == null && GroupId == null)
    end
    
    opt Có BeforeTimestamp
        Handler->>DB: Where(SentAt < BeforeTimestamp)
    end
    
    Handler->>DB: OrderByDescending(SentAt).Take(Limit).Include(...)
    DB-->>Handler: List<Message>
    deactivate DB
    
    Handler->>Handler: Reverse(Messages) để sắp xếp cũ -> mới
    Handler->>Handler: Map Messages sang ChatMessageDto
    
    Handler-->>Client: Packet [RoutingKey="chat.history.res", Payload=ChatHistoryResponsePayload]
    
    deactivate Handler
```
