# Danh sách các Use Case đã được triển khai

Dựa vào mã nguồn thực tế trong hệ thống, dưới đây là danh sách các Use Case đã được triển khai thành công, bao gồm các Use Case cốt lõi từ tài liệu thiết kế và một số Use Case mở rộng được thêm vào trong quá trình phát triển để đáp ứng yêu cầu thực tế:

*   **UC-01:** Secure Handshake (Thiết lập kênh truyền bảo mật bằng RSA/AES)
*   **UC-02:** User Registration (Đăng ký tài khoản mới)
*   **UC-03:** User Login (Đăng nhập vào hệ thống)
*   **UC-04:** Get Online Users (Lấy danh sách người dùng đang hoạt động)
*   **UC-05:** Send Message (Chat cá nhân/Nhóm/Toàn mạng)
*   **UC-06:** File Transfer (Truyền file giữa các Client thông qua UDP/TCP)
*   **UC-07:** Logout / Disconnect (Đăng xuất chủ động hoặc ngắt kết nối do rớt mạng - Heartbeat)
*   **UC-08:** Group Management (Quản lý nhóm chat: Tạo nhóm, Lấy danh sách nhóm, Thêm thành viên, Rời nhóm)
*   **UC-09:** Get Recent Chats (Lấy danh sách cuộc trò chuyện gần đây) *(Use Case mở rộng)*
*   **UC-10:** Chat History (Lấy lịch sử tin nhắn của một cuộc trò chuyện cụ thể) *(Use Case mở rộng)*
