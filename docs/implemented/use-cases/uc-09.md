# Báo cáo triển khai Use Case: UC-09 Get Recent Chats

## 1. Mô tả chi tiết
Use case **Get Recent Chats (Lấy danh sách trò chuyện gần đây)** là một tính năng mở rộng, giúp lấy danh sách những người dùng mà Client đã từng nhắn tin (PRIVATE).
Hệ thống lấy thông tin này bằng cách truy vấn bảng `Messages` trong Database để tìm kiếm các bản ghi có liên quan đến `SenderId` hoặc `ReceiverId` của User hiện tại. Đồng thời, kết hợp với `SessionManager` để kiểm tra và trả về trạng thái hoạt động thực (IsOnline) của những người dùng này.

## 2. Thiết kế lớp chi tiết (Class Design)

```mermaid
classDiagram
    class IMessageHandler {
        <<interface>>
        +RoutingKey: string
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class ServerRecentChatsHandler {
        +RoutingKey: string = "user.recent.req"
        -_serviceProvider: IServiceProvider
        -_sessionManager: SessionManager
        +HandleAsync(session: SessionHandler, payload: JsonElement) Task
    }

    class AppDbContext {
        +Messages: DbSet<Message>
        +Users: DbSet<User>
    }

    class SessionManager {
        +Snapshot() Dictionary<string, SessionHandler>
    }

    class RecentChatDto {
        +Username: string
        +DisplayName: string
        +IsOnline: bool
    }

    IMessageHandler <|-- ServerRecentChatsHandler
    ServerRecentChatsHandler ..> AppDbContext : Truy vấn lịch sử nhắn tin
    ServerRecentChatsHandler --> SessionManager : Lấy trạng thái Online
    ServerRecentChatsHandler ..> RecentChatDto : Trả về dữ liệu
```

## 3. Biểu đồ tuần tự (Sequence Diagram)

```mermaid
sequenceDiagram
    participant Client as LanChat Client
    participant Server
    participant Handler as ServerRecentChatsHandler
    participant DB as AppDbContext
    participant SManager as SessionManager
    
    Client->>Server: Packet [RoutingKey="user.recent.req"]
    Server->>Handler: HandleAsync(Payload)
    activate Handler
    
    Handler->>DB: Truy vấn `Messages` để tìm RecentUserIds
    activate DB
    DB-->>Handler: List<Guid> (recentUserIds)
    
    Handler->>DB: Truy vấn `Users` lấy thông tin Username
    DB-->>Handler: List<RecentChatDto> (recentUsers)
    deactivate DB
    
    Handler->>SManager: Snapshot() (Lấy danh sách đang Online)
    activate SManager
    SManager-->>Handler: onlineUsers
    deactivate SManager
    
    Handler->>Handler: Duyệt recentUsers, gán IsOnline = true/false
    
    Handler-->>Client: Packet [RoutingKey="user.recent.res", Payload=RecentChatsResponsePayload]
    
    deactivate Handler
```
